# Исправленные баги

1. `selectedServices`, `selectedServiceId` и `quantity` объявлялись через `let` внутри компонента. Изменения не вызывали перерисовку.
   Добавил `useState` для списка, выбранной услуги и количества.

2. Мутация состояния напрямую — использование push, splice вместо создания новых массивов
   Исправление: новый массив через spread, обновление количества через `map`, удаление через `filter` по id.

3. Повторная услуга искалась по ссылке на объект, а не по id

4. Указаны инлайн стили, это считается плохой практикой. Вынес в файлы стилизации.

5. Услугу можно было добавить с количеством `0` у поля не блокируют ввод, а кнопка проверяла только выбранную услугу.
   Исправление: количество принимается только как целое от 1 до 10. При `0` и любом другом невалидном значении кнопка «Добавить» неактивна, `addService` услугу не добавляет.
